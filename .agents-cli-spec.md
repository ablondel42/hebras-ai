# Agent Spec: Self-Improving n8n Workflow Architect (`google_adk`)

## Overview
A self-improving AI agent built on the Google Agent Development Kit (ADK) integration in `hebras-ai` and grounded in the core principles of `NEXT_SESSION.md`:
1. **Closed-Loop Grounding**: Interactively validates draft workflows against `scripts/n8n_validator.py` and reflects on diagnostic feedback.
2. **Deterministic Quality Gates**: Strictly blocks saving any workflow that fails schema, security (`SEC001`-`SEC004`), leanness (`LEAN001`-`LEAN002`), or local LLM wrapper (`LLM001`) rules.
3. **Multi-Tiered Memory & Self-Improvement**: Maintains an episodic memory store (`integrations/google_adk/memory/episodic_patterns.json`) tracking validated topologies, discovered template patterns, error reflections, and user feedback to continually improve future workflow generation.
4. **Market & ROI-Driven Web Discovery**: Web search actively targets and discovers the highest-leverage workflow opportunities by analyzing **acute customer pain points** (e.g. lead drop-off, manual data entry, customer churn, billing reconciliation) and **monetization potential** (billable automation, micro-SaaS, direct revenue lift).
5. **Local API Connection**: Operates strictly through `hebras-ai` running on `http://localhost:8000/v1` via `OpenAILlm` with model `Gemini 3.8 Flash` and `create_agent`.

## Example Use Cases
1. **High-ROI Lead Conversion**: "Find high-converting B2B lead enrichment and triage workflows that solve the pain of slow sales response times and maximize pipeline value."
   - **Agent Action**: Searches community discussions and GitHub repos for high-value CRM/lead routing patterns, synthesizes an automated enrichment workflow with `Hebras Agy Chat Model` (`http://localhost:8000/v1`), scores monetization potential, validates schema/security, saves `workflows/b2b_lead_triage/workflow.json`, and outputs documentation featuring an ROI & customer pain analysis.
2. **Revenue Recovery & Dispute Handling**: "Find how automated systems recover failed payments and chargeback disputes for Stripe/Shopify."
   - **Agent Action**: Researches payment dispute resolution patterns, extracts high-impact automated follow-up logic, ensures zero secret leakage and local model routing, saves the workflow, and documents business impact metrics.
3. **Episodic Knowledge Retrieval**: "Recall our highest-monetization customer support workflows and adapt one for automated incident triage."
   - **Agent Action**: Queries episodic memory for past high-ROI patterns, retrieves lessons learned on rate-limiting and local LLM prompt engineering, and outputs an enterprise-ready workflow.

## Tools Required
1. **`search_web_workflows(query: str, search_focus: str = "market_pain_and_roi", max_results: int = 5) -> list[dict]`**:
   - Searches the web for top-performing n8n workflows, focusing on high customer pain points, commercial viability, and monetization potential across GitHub, Reddit (r/n8n, r/SaaS), community showcases, and marketplace templates.
2. **`evaluate_workflow_roi_and_pain(workflow_summary: str, target_audience: str | None = None) -> dict`**:
   - Evaluates a workflow concept across Customer Pain Intensity (1-10), Monetization Potential (1-10), Estimated Time/Cost Savings, and Target Customer Profile.
3. **`read_local_templates(template_name: str | None = None) -> dict`**:
   - Retrieves canonical production seed templates from `knowledge/n8n/templates/` (`secure_webhook.json`, `error_handler.json`, `api_batch_polling.json`, `ai_agent_chain.json`).
4. **`validate_n8n_workflow(workflow_json: str | dict) -> dict`**:
   - Runs `scripts/n8n_validator.py` programmatically on a draft workflow, returning structured diagnostic results (valid, errors, warnings).
5. **`propose_and_save_workflow(slug: str, workflow_json: str | dict, documentation_md: str, roi_score: dict | None = None) -> dict`**:
   - Executes validation as a mandatory precondition. If valid, writes `workflows/<slug>/workflow.json` and companion `workflows/<slug>/README.md` (including Business Value & Monetization Analysis). If invalid, returns errors for self-correction.
6. **`recall_learned_patterns(topic: str | None = None, min_roi_score: int | None = None) -> list[dict]`**:
   - Recalls past workflow topologies, monetization insights, edge cases, and verified patterns from episodic memory.
7. **`record_learned_pattern(pattern_name: str, description: str, topology_summary: str, lessons_learned: str, customer_pain: str | None = None, monetization_potential: str | None = None) -> dict`**:
   - Persists a new validated pattern, pain analysis, and monetization assessment into episodic memory for future retrieval.

## Constraints & Safety Rules
1. **Local LLM Wrapper Invariant (`LLM001`)**: All LLM operations in proposed or generated workflows must route to `http://localhost:8000/v1/...` (e.g. `Hebras Agy Chat Model` with `baseURL: http://localhost:8000/v1`).
2. **Zero Plaintext Secrets (`SEC001`)**: Workflows must never contain raw API keys, passwords, or bearer tokens.
3. **Authenticated Webhooks (`SEC002`)**: Webhooks must specify authentication (`headerAuth`, `basicAuth`, or HMAC verification).
4. **Safe Code Execution (`SEC003`)**: Code nodes must not use `eval`, `child_process`, `fs`, `process.exit`.
5. **Clean PinData (`SEC004`)**: Workflows must have `"pinData": {}`.
6. **Local Runtime & Model**: The agent itself must communicate with `hebras-ai` on `http://localhost:8000/v1` using model `Gemini 3.8 Flash`.
7. **Filesystem Boundaries**: Writes are restricted strictly to `workflows/` and `integrations/google_adk/memory/`.

## Success Criteria
1. Agent initializes cleanly as `root_agent` in `integrations/google_adk/agent.py` using `create_agent` with model `Gemini 3.8 Flash` from `google_adk_integration.py`.
2. Agent connects to `hebras-ai` on `http://localhost:8000/v1` and successfully performs multi-turn interactions.
3. Agent autonomously searches web and local templates when prompted for a workflow.
4. Agent runs `validate_n8n_workflow` and demonstrates closed-loop error reflection if an initial draft contains issues.
5. Agent stores learned patterns in episodic memory and successfully recalls them in subsequent turns.
6. All output workflows in `workflows/<slug>/` pass `scripts/n8n_validator.py --strict` with 0 errors.
